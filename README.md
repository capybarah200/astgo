# AstGo — куда пойти в Астане

Помощник для прогулок по Астане. Человек пишет, где он и сколько у него времени, или нажимает на карту.
В ответ — 1–3 места рядом: сколько идти, сколько там пробыть, будет ли открыто к приходу, почему стоит
зайти и что там делать. Места складываются в короткий маршрут, который укладывается в названное время.

Сделано на хакатоне Build with AI, задание НИЦ Smart City.

Видео с работой сайта: https://youtu.be/zZHQHne1Jyo

Примеры запросов:

- «Я у Байтерека, есть час»
- «С ребёнком у Хан Шатыра, часа полтора»
- «Возле Астана Оперы, хочу кофе»
- «Доведи от Экспо до Байтерека по красивым местам»
- «Хочу пройти всю Астану» → «дальше»
- После ответа: «ещё», «ближе», «без второго», «а в 22:00?»

## Запуск

Нужен Python 3.13.

```bash
pip install -r requirements.txt
python -m app                  # http://127.0.0.1:8000
python -m pytest               # тесты
```

`python -m app --host 0.0.0.0` открывает сайт для телефона в той же Wi-Fi сети (`http://<IP-ноутбука>:8000`).
По http браузер не даёт геолокацию, поэтому место нужно написать или отметить на карте.

Время можно зафиксировать в ссылке: `/?at=23:00` посчитает ответ так, будто сейчас 23:00.

Ключ Gemini необязателен. Скопируйте `.env.example` в `.env` и впишите `GEMINI_API_KEY` (бесплатно в Google AI
Studio). Без ключа запрос разбирают правила, а текст ответа собирается из шаблонов по тем же фактам.

## Как это работает

```
реплика ─► разбор ─► подбор мест (код) ─► текст (Gemini) ─► проверка (код) ─► ответ
           Gemini    кандидаты рядом,      «почему» и          чужие места и
           или       часы работы,          «что делать»        выдуманные цифры
           правила   маршрут по времени                        отбрасываются
```

1. Разбор. Gemini возвращает JSON по схеме: где человек, куда идёт, сколько времени, с ребёнком ли, что
   интересно. Если Gemini недоступен, работают правила на ключевых словах. Место ищется по названию среди
   1872 мест базы и 2417 районов, ЖК, улиц и станций; казахские буквы приравнены к русским.
2. Подбор (`app/engine.py`). Код считает расстояние и время пешком, проверяет часы работы на момент прихода
   к каждой точке и перебором собирает маршрут из 1–3 мест разных типов. Для «до вылета» оставляется час
   на дорогу в аэропорт и регистрацию.
3. Текст (`app/llm.py`). Gemini получает только отобранные места с фактами и описаниями из Википедии и
   Wikivoyage и пишет «почему» и «что делать».
4. Проверка. Место не из подборки или число, которого нет в фактах, — и текст заменяется шаблоном. У каждого
   места подписано, откуда факты и кто написал текст.

Разговор хранится только в браузере: сервер получает контекст с репликой, отвечает и ничего не записывает.

Gemini работает цепочкой бесплатных моделей: `gemini-3.8-flash` → `gemini-3.6-flash` → `gemini-3.5-flash-lite`.
Когда у модели кончилась квота, отвечает следующая. Порядок задаётся в `GEMINI_MODEL`.

## Данные

Данные собираются скриптами в `pipeline/` и лежат в `data/`, поэтому для запуска сайта сеть не нужна (кроме
карты и Gemini).

| Скрипт | Что делает | Результат |
|---|---|---|
| `collect_osm.py` | места из OpenStreetMap (Overpass API) | `data/poi_osm.json`, 1852 точки |
| `collect_wikidata.py` | объекты Wikidata в Астане и вводные абзацы Википедии | `data/wikidata_astana.json`, 247 объектов |
| `collect_wikidata_extra.py` | типы объектов, фото Commons, статьи английской Википедии | `data/wikidata_extra.json` |
| `collect_wikivoyage.py` | описания мест из путеводителя Wikivoyage | `data/wikivoyage_astana.json`, 39 описаний |
| `build_poi.py` | склейка дублей и обогащение | `data/poi.json`, 1872 места, отчёт `reports/build_poi.md` |
| `collect_areas.py` | районы, ЖК, улицы и станции из OpenStreetMap | `data/areas_osm.json`, 2417 записей |
| `landmarks.py` | 7 ориентиров (Байтерек, Хан Шатыр, Mega…) | `data/landmarks.json` |
| `run_scenarios.py` | прогон тестовых сценариев | `reports/scenarios.md` |

Заполненность: название есть у 1101 места из 1872, часы работы — у 366, описание из Википедии — у 45, текст
путеводителя — у 27, фото — у 38. Подробно — в `reports/osm_coverage.md` и `reports/build_poi.md`.

Лицензии: OpenStreetMap — ODbL, Wikidata — CC0, Википедия и Wikivoyage — CC BY-SA 4.0, фото Commons —
с автором и лицензией каждого файла.

## Ограничения

- Часы работы есть у меньшинства мест. Без них пишем «часы неизвестны», а не «открыто».
- Время пешком — оценка по прямой ×1,3, а не маршрут по улицам. Ссылка «Маршрут пешком» открывает карту.
- Нет событий, цен, рейтингов, данных о розетках и шуме. Ассистент говорит об этом прямо.
- Адрес с номером дома не распознаётся — можно нажать на карту.
- Только Астана, только пешком, интерфейс на русском.

## Структура

```
app/        сервис: engine (подбор), hours (часы работы), places (поиск места по названию),
            query (разбор реплики), llm (Gemini и проверка ответа), texts (шаблоны),
            service (диалог), server (FastAPI), static (страница)
pipeline/   сбор и подготовка данных
data/       собранные данные
reports/    отчёты скриптов
tests/      pytest
```
